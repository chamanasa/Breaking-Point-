    Connect your Gemini API key

    AI Mode runs on Google’s Gemini models using your own free API key. The key is saved only in this browser, and your answers go straight from your browser to Google. Nothing passes through our servers.

    1. Open Google AI Studio → API keys and sign in with a Google account.
    2. Click Create API key. If prompted, pick or create a Google Cloud project; the default is fine.
    3. Copy the key. It is a long string that starts with AIza.
    4. Paste it into the box on the right and click Save & test.

    Google’s free tier has per-minute and per-day limits; a 15-minute practice case uses roughly 15–30 requests. Treat the key like a password and revoke it from AI Studio any time.
